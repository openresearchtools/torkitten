Bundled components
------------------
Tor: BSD-3-Clause and the additional notices in licenses/tor.
Caddy and Authelia: Apache-2.0; see licenses/caddy and licenses/authelia.
Chisel and gozxing: MIT and included component notices; see licenses/chisel

Complete upstream source snapshots and their exact revisions are available at
https://github.com/openresearchtools/torkitten/tree/torkitten-v2/third-party
The adjacent *.upstream.toml files identify their upstream repositories,
release tags, commits and source-tree hashes. Bundle metadata/ records the
versions used to build its executables.

and notice files. Authelia frontend dependency notices, including bundled
runtime helpers, are in licenses/authelia-web/; metadata/authelia-web-notices.json
records their exact versions and the upstream frontend lockfile hash.

System shared libraries
-----------------------
The Linux executables use replaceable, dynamically linked system libraries.
These libraries are supplied separately by the operating system; their binary
files are not included in this TorKitten bundle.

The native interface uses GTK, WebKitGTK, GLib/GObject/GIO and libsoup. These
include code under the GNU Lesser/Library General Public License (LGPL) and,
for parts of WebKit, BSD licenses. The C executables also use the system's
runtime libraries, including glibc, and Tor may use LGPL system libraries such
as libsystemd and libseccomp. Copyright remains with their respective authors.

The LGPL-2.1 text accompanies this distribution at licenses/LGPL-2.1.txt.
We use the LGPL-2.1 option where a library permits that or a later version.
You may replace these libraries with interface-compatible modified versions.
TorKitten does not restrict modification for your own use, relinking, or
reverse engineering for debugging modifications to these libraries.

Library copyright notices, exact versions and corresponding sources are
available through the operating system's package manager/source packages.
Upstream projects and source repositories:
* GTK: https://gitlab.gnome.org/GNOME/gtk
* WebKitGTK: https://webkitgtk.org/releases/
  WebKit licensing: https://webkit.org/licensing-webkit/
* GLib/GObject/GIO: https://gitlab.gnome.org/GNOME/glib
* libsoup: https://gitlab.gnome.org/GNOME/libsoup
* glibc: https://www.gnu.org/software/libc/
* systemd libraries: https://github.com/systemd/systemd
* libseccomp: https://github.com/seccomp/libseccomp
