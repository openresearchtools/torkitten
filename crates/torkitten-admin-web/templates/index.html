1

Install Tor access software

Use the official store on mobile or the official Tor Project download on desktop.

iOS · Orbot

Install Orbot from the official App Store page, open it, and finish its first-run connection.

Open official App Store page

Android · Orbot

Install Orbot from its official Google Play listing, open it, and finish its first-run connection.

Open official Google Play page

Linux · Tor Browser

Download the Linux archive, verify its signature if possible, extract it, then open start-tor-browser.desktop.

Open official Tor Browser downloads

macOS · Tor Browser

Download the macOS package from Tor Project, verify it if possible, then drag Tor Browser into Applications.

Open official Tor Browser downloads

Windows · Tor Browser

Download the Windows installer from Tor Project, verify it if possible, then complete the installer.
