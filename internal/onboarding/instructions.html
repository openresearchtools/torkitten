Install this Torkitten’s HTTPS root

HTTPS uses ordinary X.509 certificates—the standard certificate format used by TLS. This Torkitten signs its onion certificate with its own private root instead of a public certificate authority.

This temporary certificate page uses HTTP inside the end-to-end encrypted and authenticated onion connection, and Tor client authorization protects it. It serves only the public root and installation instructions. The permanent main site remains HTTPS.

iPhone or iPad

  1. Using Safari through Orbot, tap Download the iPhone certificate profile and allow the profile download.
  2. Open Settings. Tap Profile Downloaded, or open General → VPN & Device Management, then install Torkitten HTTPS Root.
  3. Open General → About → Certificate Trust Settings and enable full trust for Torkitten Root CA.
  4. Return to Torkitten and scan the permanent HTTPS onion QR.

This manually installable profile contains only the public root certificate. It does not require Developer Mode, Apple Configurator, MDM, or an Apple developer account. Apple intentionally requires the install and full-trust confirmations.

Other platforms

Download the public root certificate, then install it into the trust store used by the intended browser.

Current Tor Browser is unsupported: its default privacy policy disables local certificate roots. Do not weaken Tor Browser privacy settings to use Torkitten.

This temporary page contains no password, TOTP secret, client private key, application, or control API.
